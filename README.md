# Gothic-Remake-VR
Gothic Remake VR 0.3.291
This compact kit downloads 70.5 MB from GitHub on the first installation for UEVR and GORE. Select Install with an internet connection. Setup verifies both downloads and keeps them in %LOCALAPPDATA%/GothicVR/SetupCache for reuse. If a download fails, restore the connection and select Install again. The installer music can start once GORE is ready.

При первой установке компактная версия скачивает с GitHub 70,5 МБ для UEVR и GORE. Подключитесь к интернету и нажмите Install. Установщик проверит контрольные суммы и сохранит файлы в %LOCALAPPDATA%/GothicVR/SetupCache для повторной установки. При обрыве связи восстановите подключение и снова нажмите Install. Музыка установщика сможет заиграть после подготовки GORE.

Extract the entire archive and run Setup.exe. Select Browse… if you need to locate the game, then select Install. After installation, connect your PCVR headset and start GothicVR 0.3.291 from the desktop or Start menu.

Распакуйте архив целиком и запустите Setup.exe. Установщик на английском. Если нужно указать папку игры, нажмите Browse…, затем Install для установки. После установки подключите шлем к ПК и откройте GothicVR 0.3.291 с рабочего стола или из меню «Пуск».

This tester build includes the VR player body and hands, physical interactions, melee and ranged combat, magic, climbing, swimming, the quick wheel and playable lute. The installer plays music from Xardas’ tower using the selected installation’s own music bank. The music checkbox mutes it.

Тестовая сборка включает VR-тело и руки, взаимодействие с предметами и NPC, ближний и дальний бой, магию, лазание, плавание, круг быстрых предметов и лютню. Галочка музыки в установщике включает и выключает тему башни Ксардаса из выбранной копии игры.
